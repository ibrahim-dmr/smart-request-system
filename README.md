# SmartRequestSystem

ASP.NET Core Web API project developed with layered architecture principles.

## Technologies
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Swagger

## Features
- User listing
- Internal request creation
- Request listing
- Validation and global error handling

## Demo Scenario
The system demonstrates real-world internal request scenarios such as:
-New user account request for internal departments
-GitLab access request for software development team members
-Power BI training request for employee skill development

## Setup
1. Configure PostgreSQL connection string
2. Apply migrations
3. Run the project and test via Swagger
